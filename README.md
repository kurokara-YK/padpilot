# padpilot

**PS5のコントローラー（DualSense）**で，パソコンのマウスとキーボードの
代わりができるようになります．

キーボードもマウスも触らずに，ソファに座ったままインターネットを見られます．

> **対応しているのは PS5 のコントローラー（DualSense）だけです．**
> PS4 や Xbox のコントローラーでは動作を確認していません．

## どんなものか

ゲームのコントローラーを，マウスとキーボードの代わりにするソフトです．

- 左スティックでマウスカーソルが動く
- 右スティックで画面がスクロールする
- ○ボタンでクリックできる
- 入力欄をクリックすると，画面にキーボードが出てきて文字が打てる
- タッチパッドをなぞってもカーソルが動く
- ボタンの割り当てを**自由に変えられる**（すべてのキーに対応）

パソコンの操作に詳しくなくても使えます．
**パスワードの入力（管理者権限）は必要ありません．**

## はじめての方へ

聞き慣れない言葉が出てくるので，先に説明します．

### コントローラーとは

ゲーム機で使う，あの手に持つ機械のことです．
このソフトでは，次のものが使えます．

| 呼び名 | どんなもの |
|---|---|
| **DualSense（デュアルセンス）** | **PS5のコントローラー。これに対応しています** |

PS4（DualShock）や Xbox のコントローラーも技術的には認識されますが，
**動作確認をしていません．** 割り当てが合わない可能性があります．

### Bluetooth（ブルートゥース）とは

ケーブルを使わずに，機械どうしをつなぐしくみです．
ワイヤレスイヤホンと同じものだと思ってください．

コントローラーは，このBluetoothでパソコンとつなぎます．
うまくいかないときは，**USBケーブルでつないでも構いません．** そのほうが確実です．

### 画面キーボードとは

画面のなかに出てくるキーボードです．スマートフォンで文字を打つときに
下から出てくるもの，あれと同じです．

コントローラーには文字のキーがないので，これを使って文字を入力します．

## はじめかた

### 1. 最初の一回だけ：アプリ一覧に登録する

フォルダのなかにある，このファイルを**右クリック**します．

```
はじめにこれを実行.sh
```

出てきたメニューから **「プログラムとして実行する」** を選んでください．

しばらくすると，セットアップの画面が開きます．

> **なぜ右クリックなのか**
>
> Ubuntu 24.04 では，安全のため，フォルダのなかのファイルを
> ダブルクリックしても実行されないようになっています．
> ダブルクリックすると，かわりに文字エディタで中身が開いてしまいます．
>
> この操作が必要なのは**最初の一回だけ**です．
> 二回目からは，アプリの一覧から開けます．

<details>
<summary>「プログラムとして実行する」が出てこないとき（クリックで開く）</summary>

ファイルに実行の許可がついていない可能性があります．

1. `はじめにこれを実行.sh` を右クリック → **「プロパティ」**
2. **「アクセス権」**（または「パーミッション」）のタブを開く
3. **「プログラムとして実行可能」** にチェックを入れる
4. 閉じて，もう一度右クリック → 「プログラムとして実行する」

</details>

<details>
<summary>それでも開かないとき（クリックで開く）</summary>

端末（ターミナル）を使う方法もあります．

1. フォルダのなにもないところで右クリック → **「端末で開く」**
2. 出てきた黒い画面に，次のとおり入力して Enter を押す

```bash
bash はじめにこれを実行.sh
```

</details>

### 2. 二回目からは、アプリ一覧から開く

画面左下の **「アプリケーションを表示する」**（点が9つ並んだボタン）を押し，
**padpilot セットアップ** を選びます．

見つからないときは，検索欄に `padpilot` と入力してください．

### 3. 画面に従って進める

あとは「次へ」を押していくだけです．全部で7つの画面があります．

| | 画面 | すること |
|---|---|---|
| 1 | ようこそ | 読むだけ |
| 2 | コントローラーの確認 | つながっているか確かめます |
| 3 | セットアップの内容 | 必要なものを選びます |
| 4 | ボタンの割り当て | 変えたければ変えます |
| 5 | セットアップ中 | 待つだけ |
| 6 | 動作の確認 | **実際に動かして確かめます** |
| 7 | 完了 | 終わりです |

**6番目で必ず動作を確認します．** 動かないまま終わってしまうことはありません．

## コントローラーのつなぎかた

セットアップの2番目の画面で，つながっているか自動で調べます．
つながっていなければ，次のようにしてください．

### Bluetoothでつなぐ

1. コントローラーの **PSボタン**（真ん中の大きいボタン）と
   **Createボタン**（左上の小さいボタン）を**同時に長押し**します
2. ライトが**速く点滅**したら準備完了です
3. パソコンの「設定 → Bluetooth」を開きます
4. 一覧に出てきた `DualSense Wireless Controller` を選びます

つながると，セットアップの画面が**自動で切り替わります．**

### USBケーブルでつなぐ

ケーブルでパソコンとつなぐだけです．**こちらのほうが確実です．**
Bluetoothでうまくいかないときは，こちらを試してください．

## ボタンの割り当て

はじめは次のようになっています．**あとから自由に変えられます**（→ [使いかた](#使いかた)）．

| コントローラー | はたらき |
|---|---|
| 左スティック | カーソルを動かす |
| 右スティック | 画面をスクロールする |
| 十字キー | 矢印キー（↑↓←→） |
| ○ボタン | クリック |
| ×ボタン | Enter（決定） |
| □ボタン | コピー（Ctrl+C） |
| △ボタン | 貼り付け（Ctrl+V） |
| L1 | Esc（取り消し） |
| R1 | Tab |
| SHARE | Alt+Tab（画面の切り替え） |
| OPTIONS | Shift |
| PSボタン | 右クリック |
| L3（左スティック押し込み） | Backspace（1文字消す） |
| R3（右スティック押し込み） | Delete |
| タッチパッドをなぞる | カーソルを動かす |
| タッチパッド押し込み | クリック |

### カーソルの速さを変える

| 操作 | 速さ |
|---|---|
| そのまま | ふつう（60） |
| **R2を押しながら** | 速い（175） |
| **L2を押しながら** | ゆっくり（20） |

細かい操作をしたいときはL2を押しながら動かすと合わせやすくなります．

## 文字を入力する

**入力欄をクリックすると，画面キーボードが自動で出てきます．**

検索欄などをクリックしてみてください．画面の下からキーボードが現れます．
あとは，カーソルを動かして○ボタンで文字を選びます．

日本語も入力できます．

> タッチパッドを押し込んでもキーボードは出ません．
> 押し込みは「クリック」として働きます．

## 使いかた

アプリの一覧から **padpilot** を開くと，設定画面が出ます．

| 画面 | できること |
|---|---|
| ホーム | 今の状態を見る．**開始・停止** |
| ボタンの割り当て | **ボタンの役割・速さを変える** |
| 調子を確認する | うまく動かないときに原因を調べて直す |

### ボタンの割り当てを変える

1. アプリ一覧から **padpilot** を開く
2. 左の **「ボタンの割り当て」** を選ぶ
3. 変えたい行の右側をクリックして，やりたいことを選ぶ
4. **「保存する」** を押す

使っている最中でも，保存するとすぐに切り替わります．

**割り当てられるもの**

| 種類 | 例 |
|---|---|
| 文字 | A〜Z，0〜9，記号 |
| ファンクションキー | F1〜F35 |
| 特殊キー | Enter，Esc，Tab，矢印，Home，PageUp，半角/全角 など |
| マウス | 左/右/中クリック，ホイール上下左右，戻る・進む |
| 組み合わせ | Ctrl+C，Alt+Tab など．**3つ以上も作れます** |

**自分で組み合わせを作る**

一覧のいちばん下の **「＋ 組み合わせを作る…」** を選ぶと，
`Ctrl + Shift + F5` のような組み合わせを自由に作れます．

### セット（3つの設定を切り替える）

**3つの設定を登録**でき，L2・R2を押している間だけ切り替わります．

| セット | いつ使われるか | カーソルの速さ |
|---|---|---|
| 1. 通常 | ふだん | 60 |
| 2. 高速 | **R2を押している間** | 175 |
| 3. 低速 | **L2を押している間** | 20 |

画面上の **「設定するセット」** を切り替えると，
セットごとに割り当てと速さを変えられます．

たとえば「ふだんは○＝クリック，R2中は○＝Enter」といった使い分けができます．
**カーソルの速さ**もこの画面の下で変えられます．

### 「調子を確認する」とは

うまく動かないときの**点検**です．「調べる」を押すと自動で確かめます．

- コントローラーがつながっているか
- 必要なソフトが入っているか
- 画面キーボードの設定が正しいか
- 他のソフト（Steamなど）と重なっていないか

問題が見つかると，**その場で直せるものは「直す」ボタンが出ます．**

### アイコンを右クリックしてできること

| 項目 | すること |
|---|---|
| コントローラーを使えるようにする | 開始 |
| コントローラーを止める | 停止 |
| 設定・調子を確認する | 設定画面を開く |

## やめるとき

コントローラーを使うのをやめたいときは，アプリ一覧の padpilot から
「完全に終了」を選びます．

**パソコンから完全に消したいとき**は，アプリ一覧から
**padpilot の削除** を開いてください．

アプリ一覧に無いときは，`uninstall.sh` を右クリックして
「プログラムとして実行する」を選びます．

入れたものはすべて消え，パソコンは元どおりになります．

## うまくいかないとき

まず，アプリ一覧から **padpilot** を開いて「診断」を押してください．
原因と直しかたが日本語で出てきます．直せるものは**その場で直せます．**

### カーソルが動かない

1. コントローラーのPSボタンを一度押してみてください
2. それでも動かないときは「診断」を実行してください

### 文字が入力できない

画面キーボードが入っていない可能性があります．
「診断」を実行すると分かります．

### 画面キーボードにカーソルを重ねると落ちる

padpilot の「調子を確認する」で点検し，「見つかった問題を直す」を実行してください．
onboard のポインタ入力方式を GTK に切り替えます．
変更後は画面キーボードを閉じて，もう一度開いてください．
詳しい再検証結果は [検証記録](docs/keyboard-revalidation.md) にあります．

### コントローラーがつながらない

USBケーブルでつないでみてください．そのほうが確実です．

### セットアップで「うまくいきませんでした」と出る

**HTTP Error 500** などと出た場合，配布元（GitHub）が一時的に
応答していないだけのことがほとんどです．**あなたの操作は間違っていません．**

**「もう一度試す」** を押してください．それでもだめなら，
数分〜十数分ほど待ってからやり直してください．

自動で4回まで試すようになっているので，一時的な不調なら
そのまま成功することが多いです．

| 出るメッセージ | 意味 | どうするか |
|---|---|---|
| 配布元が応答しません (HTTP 500) | GitHub側の一時的な不調 | 少し待ってやり直す |
| インターネットに接続できません | ネットにつながっていない | 接続を確かめる |
| ファイルが見つかりません (HTTP 404) | 配布先が変わった | 開発者に連絡 |

### カーソルが勝手に動く / 二重に動く

Steamが起動していると，Steamの機能と重なることがあります．
Steamを終了してみてください．

## しくみ

このソフト自体はコントローラーを読み取っていません．
**AntiMicroX** というソフトに任せています．

```
コントローラー
    ↓
AntiMicroX          ← ボタンをマウス・キーボードの動きに変える
    ↓
padpilot            ← AntiMicroXの導入と管理をする（このソフト）
```

AntiMicroXは，セットアップのときに公式サイトから取り込みます．
このフォルダのなかには入っていません．
